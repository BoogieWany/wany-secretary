# wany-secretary

부원장 전용 비서 — 오늘(시간표 연계) · 기록(회의 안건 · 기억할 일 · 아이디어) · 알림.

- `index.html` — 폰·PC 브라우저가 같이 여는 화면. 홈 화면에 설치할 수 있음(`manifest.webmanifest` · `sw.js` · `icon-*.png`)
- `data.json` — 내 기록 보관함 (잠그지 않고 그대로 저장 — 저장소가 공개라 누구나 읽을 수 있음). 연결 키(이 저장소 Contents 읽기·쓰기)로 읽고 씀
- **오늘** 탭 — 같은 주소의 `ymath-timetable/view.json`(암호화된 폰 시간표 자료)을 받아, 시간표 로그인 코드로 풀어서 내 것만 보여 줌:
  오늘 수업 · 내 업무 · 다가오는 시험 · 보강 · 지정 상담 · 신입예정(입학 예정 · 문의). 시간표 쪽은 읽기만 하고 아무것도 바꾸지 않음.
  푼 내용은 이 기기 브라우저에만 남고 저장소에는 올라가지 않음. 시간표 자료 형식(enc 2)이 바뀌면 `ttOpen` · `summ` 을 같이 고쳐야 함
- 아이콘: 안경 + W (`icon.svg` 원본 → `icon-192.png` · `icon-512.png`)
